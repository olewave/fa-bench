# TIMIT results — moved

> **This page has moved.** Results are now filed by *where the words came
> from* rather than by system type, because that is the only split that
> affects comparability: with a gold transcript the boundary error is pure
> timing, while with an ASR transcript a misrecognised word leaves the
> matched path and the average is taken over an easier subset.
>
> ```
> records/<yyyymm>/en/{gold,asr}/{word,phone}/<corpus>/
> ```

The word and phone tiers are separate pages now: they never held the same
systems, and mixing them meant comparing a six-system ranking against an
eleven-system one.
